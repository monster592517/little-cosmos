# 启动器中文注释原文（从 START.bat 搬出来）

## 为什么搬出来

（包内叫 ）**必须是纯 ASCII**。
cmd.exe 按本地 OEM 代码页读 .bat：同一份 UTF-8 中文在中文机按 GBK 解、英文机按 CP437 解，
**中文的字节可能解出 `&` / `|` / `>` 这类控制字符**，于是 **rem 注释行会被当成命令执行**。
2026-09-15 实测就是这条故障：屏幕刷满

```
'口看起来是黑?—?' 不是内部或外部命令，也不是可运行的程序或批处理文件。
```

**并且它把启动器从那一行起打断** —— 表现为「服务起来了，但浏览器不打开」，
而且日志恰好停在 `server up on 8787` 之后。

⚠️ 所以：**不要把这些中文搬回 .bat**。要写注释就用英文，或者写在这个文件里。
